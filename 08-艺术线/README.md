# 艺术线 / 叙事创作骨架

> **什么时候用这条线：** 「三个开关」里 **规模 = 流程** 且 **风格 = 叙事片或艺术片** 时。
> 拍门店引流、产品测评的，不用进来。

---

## 一、这条线和主流程什么关系

**主干是同一条，这条线只换后半段的组织方式。**

```
商业骨架：01 需求 → 02 清单 → 03 采集 → 04 回收 → 05 身份资产
          → 06 参考拆解 → 07 脚本改造 → 08 客户确认 → 09 提示词编译

叙事骨架：01 概念 → 02 角色 → 03 世界观(可选) → 04 分场
          → 05 剧本 → 06 图像资产 → 07 表演 → 08 镜头与提示词
```

**对接点：** 商业骨架跑完 **08 客户确认**，如果这条片子要做成系列、要复用角色和场景，就从这里**切进叙事骨架的 04 分场**，往后走。

**不要两套都从头跑**——需求、素材、客户确认这几步是重复的。

---

## 二、八个阶段各干什么

| 阶段 | 干什么 | 交什么 | 过不过关看什么 |
|---|---|---|---|
| 01 概念锚定 | 定主题、类型、受众、核心命题 | 故事大纲 | 一句话说得清"这故事讲什么" |
| 02 角色圣经 | 人物想要什么、什么挡着他 | 角色卡 | 每个角色都有欲望和阻力 |
| 03 世界观（可选） | 规则、阵营、地点、关键物件 | 设定表 | 现实题材直接跳过，别硬造 |
| 04 分场大纲 | 逐场拆：这场干什么、多长、值不值 | 场次表 | 每场都有"变化"，没有原地踏步的场 |
| 05 剧本 | 写成能拍、能排练、能交接的正文 | 剧本 | 台词能念出来，动作能比划出来 |
| 06 图像资产 | 角色/场景/道具的描述符与提示词 | 资产图 | 同一角色跨镜长相一致 |
| 07 表演 | 目标、阻力、策略、节拍、潜台词、可见行为 | 表演说明 | 不看台词也知道这人在想什么 |
| 08 镜头与提示词 | 拆镜头清单 → 出视频模型提示词 | 镜头表 + 提示词 | 每镜过「六问」 |

**顺序铁律：** 先定概念，再定人，再拆场，再写正文，最后审一遍。**前一步没定，别急着走下一步。**

## 三、三个必须借的机制

### 机制 1：一次只跑一个阶段

不要一句话让它"从头到尾给我出一部片"。会乱。

一次只做一个阶段，做完确认，再进下一个。

### 机制 2：回退只重算受影响的部分

改第 8 场，只重做这场涉及的资产、表演、提示词，其余**标记为"可能过期"**，不推倒重来。

口令：

```
回到剧本阶段：修复第 8 场主角动机，先不要重做下游。
确认后：只重做第 8 场受影响的资产、表演和镜头提示词。
```

### 机制 3：新项目不能被旧项目污染

新项目开张时**不要**带着上一部片的角色卡、提示词、资产图。

干净起步，比"参考一下上次那个"重要得多。

## 四、最贵的一次翻车：跳过压力测试

在开烧之前，问三个问题：

| 问 | 不合格的表现 |
|---|---|
| 这个故事**一句话**讲得清吗 | 要讲三分钟才说明白 |
| 每一场都有**变化**吗 | 有场次只是"交代信息" |
| 观众**为什么要看下去** | 答不上来，只能说"画面好看" |

**为什么这一步最贵：** 结构死掉的剧本和结构活着的剧本，AI 生成出来**一样干净**。模型不在乎你的剧本配不配被生成。等你在剪辑台上发现不对，钱已经烧完了。

## 六、什么时候不该进这条线

- 客户只给三天
- 片子 30 秒以内
- 有明确的商品必须还原
- 客户已经给了逐字稿，且不接受改结构

这四种情况，走商业骨架的手搓路径，两天能交。
