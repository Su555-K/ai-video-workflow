# 语速与时长核算表

> 填完这张表，能回答一个问题：**这句台词，排的这点时间够不够念完。**

**定位：这是预警表，不是判死表。** 它告诉你哪里会赶、哪里会拖，不替你做决定。风格、停顿、故意留白都可以突破参考值——但要知道自己突破的是哪一条。

---

## 一、什么时候用

| 场景 | 这张表的作用 | 能不能改脚本 |
|---|---|---|
| **原创脚本** | 约束——写的时候就按语速排 | 能改，超了就删字或加时长 |
| **复刻脚本** | 预警——提前知道哪句会赶 | **不能改**，改写会破坏复刻 |

复刻场景里，如果算出「念不完」，**第一反应不是「脚本错了」，而是「我们对原片的读数可能有误」**——回去核对原片那一镜到底几秒、有没有剪掉半句。

---

## 二、算法（比「字数 ÷ 语速」准）

```
需要时间 = 音节数 ÷ 语速 + 停顿时间
再 × 1.1（口语冗余：人会加"就是""但是"，会打磕巴）
```

### 音节怎么数

| 类型 | 规则 | 例 |
|---|---|---|
| 汉字 | 1 字 = 1 音节 | 看这个和牛 = 5 |
| **数字** | **按读法，不是按字符** | `138` = 一百三十八 = **5**；`400多` = 四百多 = **3**；`200多` = 二百多 = **3** |
| 英文 | 按音节 | `New` = 1；`M9` = 艾姆九 = 2 |
| 标点 | **不算音节，算停顿** | — |

### 停顿怎么算

| 标点 | 停顿 |
|---|---|
| 逗号 `，` | 0.25 秒 |
| 顿号 `、` | 0.2 秒 |
| 句号 `。` / 问号 `？` | 0.45 秒 |
| 感叹号 `！` | 0.4 秒 |
| 省略号 `…` | 0.6 秒 |

### 语速参考（不是红线）

| 片型 | 字/秒 | 说明 |
|---|---|---|
| 平静讲解、招商口播 | 4.0 | 慢，有分量 |
| 常规口播 | 4.5 | 默认 |
| **探店、带货、信息流** | **5.5–6.0** | 快，但不赶 |
| 情绪激动、喊话 | 3.5 | 慢，有情绪 |

**上限：超过 6.5 字/秒，基本就是念不完。** 不是风格问题，是生理问题。

## 三、填表

### 空表

| 镜号 | 排的时长 | 口播原文 | 音节 | 停顿 | 需要时间 | 差 | 判定 |
|---|---|---|---|---|---|---|---|
| S01 | 2.0 |  |  |  |  |  |  |
| S02 | 1.5 |  |  |  |  |  |  |
| S03 | 1.5 |  |  |  |  |  |  |
| … |  |  |  |  |  |  |  |

**差 = 排的时长 − 需要时间**（正数=富余，负数=不够）

### 判定档

| 差 | 判定 | 怎么办 |
|---|---|---|
| **< −1.2 秒** | 🔴 **念不完** | 删字 / 加时长 / 复核原片读数 |
| −1.2 ~ −0.5 | 🟡 偏紧 | 提速念，或赶一赶 |
| −0.5 ~ +0.5 | ✅ 合适 | 不用动 |
| +0.5 ~ +1.0 | 🟢 宽松 | 可以有停顿，更自然 |
| **> +1.0 秒** | 🔵 富余 | 加内容，或缩短（要确认是不是故意留白） |

**⚠️ 有一类不算富余**：空镜、展示、动作完成——画面本身需要时间，多出来的时间是给观众看的，不是注水。

## 四、两个真实案例

### 案例 A：复刻脚本 01（15 秒 · 9 镜）

全片 52 音节 / 15 秒 = **3.47 字/秒**，低于探店片标准，但画面撑得住。

| 镜号 | 时长 | 口播 | 音节 | 需要 | 差 | 判定 |
|---|---|---|---|---|---|---|
| 01 | 2.0 | 看这个M级和牛 | 7 | 1.40 | +0.60 | 🟢 宽松 |
| 02 | 1.5 | 下锅涮5秒 | 5 | 1.00 | +0.50 | ✅ |
| 03 | 1.5 | 裹上无菌蛋 | 5 | 1.00 | +0.50 | ✅ |
| 04 | 1.5 | 入口即化 | 4 | 0.80 | +0.70 | 🟢 |
| 05 | 1.5 | 奶香十足 | 4 | 0.80 | +0.70 | 🟢 |
| 06 | 2.0 | 关键是无限续 | 6 | 1.20 | +0.80 | ✅ 画面驱动 |
| 07 | 1.5 | 想吃多少吃多少 | 7 | 1.40 | +0.10 | ✅ 画面驱动 |
| 08 | 1.5 | 明晚某火锅品牌直播间 | 7 | 1.40 | +0.10 | ✅ 画面驱动 |
| 09 | 2.0 | 和牛自由等你来 | 7 | 1.40 | +0.60 | ✅ 画面驱动 |

**合计需要 10.40 秒，全片 15 秒 → 富余 4.60 秒。没有一句念不完。**

富余都落在画面驱动镜（涮肉、裹蛋、咀嚼、肉塔展示），是给观众看清动作的时间，不是注水。**这条片的语速是对的——少说话，多展示。**

### 案例 B：复刻脚本 02（20 秒 · 9 镜）

全片 79 音节 / 20 秒 = **3.95 字/秒**，整体偏慢，但**分配严重不均，且总量超载**。

| 镜号 | 时长 | 口播 | 音节 | 停顿 | 需要 | 差 | 判定 |
|---|---|---|---|---|---|---|---|
| 01 | 3.0 | 日料店点一盘M9和牛，多少钱？ | 13 | 0.70 | 3.30 | −0.30 | ✅ |
| **02** | **3.0** | **138一盘，三盘就400多。但在某火锅品牌，200多，这些全畅吃** | **25** | **1.20** | **6.20** | **−3.20** | 🔴 **念不完** |
| 03 | 2.0 | M级和牛也畅吃 | 7 | 0 | 1.40 | +0.60 | 🟢 |
| 04 | 2.0 | 甜虾 | 2 | 0 | 0.40 | +1.60 | ✅ 展示 |
| 05 | 2.0 | 生蚝 | 2 | 0 | 0.40 | +1.60 | ✅ 展示 |
| 06 | 2.0 | 整盘虾山 | 4 | 0 | 0.80 | +1.20 | ✅ 展示 |
| 07 | 2.0 | 海鲜档随便拿 | 6 | 0 | 1.20 | +0.80 | ✅ 展示 |
| 08 | 2.0 | 甜品也安排 | 5 | 0 | 1.00 | +1.00 | ✅ 展示 |
| 09 | 2.0 | 明晚某火锅品牌直播间，价格更低，记得来抢 | 15 | 0.50 | 3.50 | −1.50 | 🔴 念不完 |

**三个红点：**

1. **02 镜差 3.20 秒** —— 全片最核心的价格对比，给了最紧的时间
2. **09 镜差 1.50 秒** —— 结尾引导语念不完
3. **全片台词需要 18.20 秒，超过底线 18.0 秒（20×0.9）** —— 整条片的台词量已经装不下

第 3 条最关键：**这不是某一镜的问题，是全片塞太满。** 就算 02 镜和 09 镜各让出 1 秒，也没地方可让，除非砍内容或加时长。

而 04–06 的「甜虾」「生蚝」「整盘虾山」各占 2 秒，属于展示类（要让观众看清），**不算注水**。

**这就是「重点错配」**：卖点最重的地方时间最少，展示最轻的地方时间最多。

## 五、复刻场景专项：算出念不完怎么办

因为是复刻，不能改脚本。这时候按这个顺序查：

| 顺序 | 查什么 | 怎么查 |
|---|---|---|
| 1 | **原片这一镜真是 3 秒吗** | 回去数格子/看时间码，很多时候读数就错了 |
| 2 | **原片这句是念完了，还是被剪掉了半句** | 复刻最容易漏「原片其实删了半句」 |
| 3 | **原片这一镜是不是画面先出、声音后进**（J-cut） | 声音从前一镜开始，画面后切，能多出 1 秒 |
| 4 | **原片有没有叠字/字幕帮忙** | 口播没念的，字幕补了 |

**前三条查完还是不够，就说明这条复刻在物理上做不到原样** —— 这是要跟客户说的事，不是学生能自己解决的。

## 六、自动化

`scripts/calc_pace.py` 可以批量算：

```bash
python3 scripts/calc_pace.py 脚本.txt --pace 5.5
```

输入格式（每镜一行）：

```
01|2.0|看这个M级和牛
02|1.5|下锅涮5秒
```

输出逐镜音节、需要时间、差值、判定。

**手算也行** —— 表就四列，念一遍用手机计时更准。

## 七、和 v0.7 规则的关系

| v0.7 原规则 | 本表补充 |
|---|---|
| 字数 ÷ 语速 | **音节** ÷ 语速（数字按读法） |
| 未计停顿 | **加停顿**（逗号 0.25 / 句号 0.45） |
| 未计口语冗余 | **×1.1** |
| 单镜超 1.5 倍 = 注水 | **区分**：空镜/展示/动作类的富余不算注水 |

原规则的判断框架是对的（先判档、按镜头类型、画面优先），只是**算法偏乐观**。本表不改框架，只把算得更准。

## 八、本表算的是「容量」，不是「语速」

这张表的「需要时间」和「差」，回答的是**这一镜装不装得下**，不回答**语速密不密**。两个问题用两个分母，不要互相替代：

| 问题 | 用什么算 | 判定 |
|---|---|---|
| 装不装得下（**容量**） | 需要时间（本表）vs 剪辑时长 | 差 ≥ −1.2s；超了删字或加时长 |
| 密不密（**语速**） | 台词字数 ÷ **说话窗口** | 3.5–6.5 字/秒；分母定义见 07「三条禁止」 |

**一个实测例子**（30 秒 10 镜探店稿，台词 98 字）：

- 按整镜时长算：98 ÷ 30 = **3.27 字/秒** → 会被误判「密度不足」，整条退回
- 按说话窗口算：窗口合计 26.2 秒，逐镜 **3.57–3.93 字/秒** → 合格

**同一份稿，分母不同，结论相反。** 整镜时长里含着推镜、定格、等动作的秒数，那些秒本来就不该有台词。
