## 先判档，再打分

| 档 | 时长 | 用哪套表 | 留人靠什么 |
|---|---|---|---|
| **S** | ≤60s | 十项卡 | 前 3 秒决定生死 |
| **M** | 60–120s | 十项卡，第 5 项改判 | 前 3 秒 + 中段二次钩子 |
| **L** | >120s | 长视频十项 | 未完成感 |

**判错档，后面全错**：60 秒以上的片子套 S 档，"8 秒兑现"永远得 0 分，会被误判成必须重写。

判定线：`<14 分退回重写 / 14–15 定向返工 / ≥16 可发`

**硬规则优先**：第 5 项（8 秒兑现）或第 6 项（证据位）任一为 0，无条件重写，不看总分。

## 两种病，改法相反

| 病 | 症状 | 改法 | 返工量 |
|---|---|---|---|
| **结构塌陷** | 中段连续多镜说同一件事，空转十几秒 | **删**（删镜头、压时长） | 小 |
| **证据缺失** | 大段口播全是形容词和名词短语，无一可验证 | **补**（插证据段） | 大 |

**搞反了就是白干。** 先判病，再动手。

## 语速：先定约束，再算时长

> **核心一条：不管片子多长，语速该多少就多少。不许因为时长要求把语速拉快或拖慢。**

### 什么时候适用（条件必检）

| 镜头类型 | 语速约束 |
|---|---|
| **A 纯口播** | ✅ 强约束，**语速直接决定时长** |
| **B 台词 + 动作** | ✅ 取两者较大值 |
| **C 纯动作** | ❌ 不涉及 |
| **D 空镜 / 转场** | ❌ 不涉及 |
| **E 留白** | ❌ 不涉及 |
| **F 台词跨镜** | ✅ 音轨连续，按整体算 |

**不是每镜都要查，但有台词就必须过这一项。** 这就是"需要通过的选项"——按需触发，触发即硬约束。

### 先定节奏，再定约束

排时长前先回答：**这一段靠什么留人？**

| 节奏类型 | 靠什么留人 | 时长怎么定 |
|---|---|---|
| **动作型** | 动作完成度 | 动作跑完为准，**宁可长** |
| **情绪型** | 停顿和呼吸 | 留白优先，不要塞满 |
| **口播型** | 信息密度 | **语速决定时长** |

> **画面完整性优先于时长整齐。** 一个动作没做完就切，比多两秒更伤。

**没有其他动作、环境、必要空镜时，就按语速排。** 有的话，以画面为主，语速在该镜内部再调。

### 纯口播的五层约束

交给 agent 时，五项要全给：

| # | 层 | 内容 |
|---|---|---|
| 1 | **语速目标** | 按片型取：平静 4.0 / 常规 4.5 / 探店 5.5–6.0 / 情绪 3.5 字每秒 |
| 2 | **语调** | 陈述 / 疑问 / 感叹，一句只能一种 |
| 3 | **断句** | 每句 ≤15 字（长句会自然加速） |
| 4 | **停顿点** | 标在哪停、停多久（0.3–0.8 秒） |
| 5 | **总时长** | 由前四项算出，**不参与反向调整** |

**第 5 条是关键：总时长是结果，不是输入。**

### 三条禁止

**先明确分母：这一章所有「字/秒」一律按「说话窗口」算，不按整镜时长算。**

> **说话窗口** = 该镜里真正能开口的秒数 = 剪辑时长 − 起手约 0.3s − 收尾约 0.3s − 镜内静默（等动作、等反应、故意留白）。
> 把镜时长直接当分母算出来的那个数（总字数 ÷ 全片时长）叫**全片密度**，不是语速：空镜、动作、留白多的片子必然只有 2–3 字/秒，它**不参与判定**。

1. **不许为了卡时长加速念** → 快过 6.5 字/秒就是念不完
2. **不许为了填时长放慢念** → 慢过 3.5 字/秒就是拖
3. **不许用"放慢语速"解决字数不够** → 字数不够就是内容不够，要加内容

### 三个数不要混：语速 / 容量 / 占比

| 数 | 怎么算 | 判什么 | 判定线 |
|---|---|---|---|
| **语速** | 台词字数 ÷ **说话窗口** | 密不密 | 3.5–6.5 字/秒；>6.5 念不完，<3.5 太空 |
| **容量** | 核算表的「需要时间」vs 剪辑时长 | 装不装得下 | 核算表「差」≥ −1.2s；超了删字或加时长 |
| **占比** | 台词总时长 ÷ 全片时长 | 有没有呼吸 | ≤ 0.9 |

**三者怎么配合**：容量不过 → 先删字或加时长，不许靠缩窗口把语速做进区间；语速低于 3.5 → 字太少，补内容或压时长；占比超 0.9 → 整条重排，不是某一镜的事。

**窗口上限就是 剪辑时长 − 0.6s，不能把整镜时长当窗口。** 反过来，把窗口压小只会把语速推高，压到 6.5 以上照样判念不完——**缩分母不能把「念不完」变成「合格」**。

### 客户指定总时长，但文案念不完怎么办

只有两条路：

| 路 | 做法 | 代价 |
|---|---|---|
| **删字**（推荐） | 砍到能念完 | 丢信息，但节奏对 |
| **加时长** | 和客户谈 | 改预期，可能超平台上限 |

**没有第三条"念快点"。**

### 一个不用工具的检查

排完时长问一句：**这段台词按正常语速念一遍，需要几秒？**

和排出来的时长**差超过 20%，就是排错了**。

让学生自己念一遍——手机计时就行，不需要任何软件。

## 时长核算：按镜头类型算，不要一刀切

**这一条修正了我们之前的算法。** 以前写「字数 ÷ 4.5~5」，那只对纯口播成立。

台词在音轨层，镜头在画面层，两者可以不同步。

| 类型 | 算法 | 例 |
|---|---|---|
| **A 纯口播** | 字数 ÷ 语速 | 数字人口播 |
| **B 台词 + 动作** | **取两者较大值，不相加** | 边翻肉边说 |
| **C 纯动作** | 动作节点 × 1.2–1.8 秒 | 夹子被抽走 |
| **D 空镜/转场** | 0.5–2 秒，**不套公式** | 矿山碎石 |
| **E 留白** | 设计值 | 吃完沉默两秒 |
| **F 台词跨镜** | 音轨连续、画面切 | 一句话念 5.6 秒，画面切三次 |

语速按片型取：

| 场景 | 字/秒 |
|---|---|
| 平静讲解、招商口播 | 4.0 |
| 常规口播 | 4.5 |
| 探店、带货、信息流 | 5.5–6.0 |
| 情绪激动、喊话 | 3.5 |

**两条底线**：

1. 台词总时长 ≤ 全片 × 0.9（留 10% 呼吸）
2. 单镜实际时长超过应占的 1.5 倍 = 注水。**先砍台词，再砍镜头**——砍镜头会伤结构。

**每镜都要能反推出「这句几秒」，不能只在心里估。**

### 怎么算准：见 [语速时长核算表](语速时长核算表.md)

v0.7 的「字数 ÷ 语速」偏乐观，三个地方低估了：

1. **数字按字符算** —— `138` 是 3 个字符，念出来是「一百三十八」**5 个音节**
2. **标点停顿没算** —— 逗号 0.25 秒、句号 0.45 秒，没人念标点
3. **口语会自然加词** —— 人会加「就是」「但是」，会打磕巴

那张表改成 `音节 ÷ 语速 + 停顿`，再乘 1.1 的容错。还带 `scripts/calc_pace.py`，脚本文件批量算：

```bash
python3 scripts/calc_pace.py 脚本.txt --pace 5.5 --total 20
```

**一个实测例子**：`138一盘，三盘就400多。但在某火锅品牌，200多，这些全畅吃` 按字数算需要 4.55 秒，按音节+停顿算需要 **6.20 秒**——排 3 秒的话，差 3.2 秒，怎么念都念不完。

**复刻场景特别注意**：算出念不完，第一反应不是「脚本错了」，而是**回去核对原片这一镜真实几秒、有没有剪掉半句**。复刻任务不能改脚本，表的作用是提前知道哪里会赶。

## 交付八项，第 8 项最重要

1. 诊断（打分 + 结论）
2. 改动清单（原句 → 改后 → 为什么）
3. 改后分镜表
4. 镜头级对照 + 时长去向
5. 配套物料（标题 3 版 / 封面 1 版 / 置顶评论 1 条）
6. 需客户确认项（留 ⬜）
7. **原稿保留部分**——哪些一字未改、为什么
8. **干净分镜表（音画分离）**——唯一给下游的文件，**两张表，不是一张**

**为什么第 8 项重要**：诊断文档里混着原句对照和删除标记，生成的人照着做，会把**已经删掉的镜头也做出来**。

**必须是两张表，不是一张：**

| 表 | 交给谁 | 只写什么 |
|---|---|---|
| **上表 · 画面** | 视频模型 | 镜号、时长、画面（起→变→停）、素材、生成备注 |
| **下表 · 音频** | 配音 / 剪辑 | 镜号、时长、旁白原文、音效、音乐、备注 |

**这是硬要求，不是建议。** 台词和画面写在同一行，视频模型会把台词也「画」出来——这是生成出字幕的头号原因。

模板见 [干净分镜表](../../05-学生包/模板/干净分镜表.md)，原因见 [文字策略排查](../09-提示词编译/文字策略排查.md)。

**给视频模型的提示词里，一句台词都不能出现。**

## AI 可做性：事实必须真，画面可以生成

| 素材 | 能做 | 不能做（红线） |
|---|---|---|
| 产品外观 | 真图驱动，外观可保持 | 改花纹、改文字、改结构 |
| 人物反应 | 可生成，但**不能声称是真实顾客** | 真实评价、交易记录、回头率 |
| 使用场景 | 矿山、工地、厨房都能生成 | 真实门店内部（装修会对不上） |
| 过程演示 | 生到熟、铺到翻 | 需精确计时的工序（"三分钟出餐"） |
| 数据参数 | **完全不生成** | 全部走后期字幕 |

## 硬约束：不许增加字幕

> **分镜里不许出现「加字幕」「画上文字」「屏幕上显示」这类要求。**

字幕是后期的事，不是生成的事。分镜里写一句「画面出现店名」，模型就会去画字，画出来是乱码。

**唯一例外**：字幕文本本身要写进**声音表**（旁白原文那一列），那是给剪辑时做字幕用的文本，不是让模型画。

分镜里能出现文字的只有一种情况：**画面里原本就有的字**（门头、招牌、价签），这类必须在画面列标注「原图直出」或「锁首帧保留」，见 [文字策略排查](../09-提示词编译/文字策略排查.md)。

## 过关（九条，能勾）

交付前逐条过。**不过关不许进 07。**

- [ ] 每条台词都算了时长，卡片里**留着算式**（`18 字 ÷ 4.5 = 4.0s`）
- [ ] 每镜标了镜头类型（A 纯口播 / B 台词+动作 / C 纯动作 / D 空镜 / E 留白 / F 跨镜）
- [ ] **台词总时长 ≤ 全片 × 0.9**（留 10% 呼吸）
- [ ] 没有超过 **6.5 字/秒**的句子（按说话窗口算，见「三条禁止」的分母说明；超了就是念不完）
- [ ] 没有低于 **3.5 字/秒**的句子（按说话窗口算；低了就是拖）
- [ ] 干净分镜表**音画分离**：画面表 5 列 + 声音表 6 列，**镜号连续不跳**（S01、S02…）
- [ ] 干净分镜表里**没有批注**（诊断、理由、删除标记全留在诊断版）
- [ ] 第 7 项「原稿保留部分」写了：哪些一字未改、为什么
- [ ] **分镜里没有「加字幕」类要求**；出现的文字都是画面原有的，且标了「原图直出 / 锁首帧保留」

**前四条任一不达标，退回重排；后四条影响下游能不能接。**

## 常见卡点

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 客户说 30 秒就拆 30 秒 | 没先算 | 先算字数÷语速，超了拿去谈 |
| 全片念不完但每镜看着都还行 | 没算总量 | 台词总时长 ≤ 全片×0.9，超了整条重排 |
| 边说边做的镜时长长了 | 两段时间相加了 | **取较大值，不相加** |
| 空镜/展示镜被判"注水" | 套了台词公式 | 空镜 0.5–2 秒，富余是给观众看的 |
| 改完不知道哪条起作用 | 一次改了多处 | **每轮只改一个变量**，并记录 |
| 打分次次满分 | 为了让分数好看 | 够不着就写"受素材限制只能到 1 分" |
| 下游把已删镜头也做了 | 干净版混了诊断标记 | 干净版单独出，不带任何批注 |
