# 02 · 素材清单

> 把「要什么素材」写成客户能照着拍的清单。
> **写不成客户能拍的样子，就等于没写。**

| | |
|---|---|
| **上一步给我什么** | 定稿的一表通（**含制作方式**） |
| **这一步交什么** | 素材采集清单（含分镜对照表、回收表、合规项） |

---

## 做什么

**① 按七章模板填**

店招门头 / 环境空镜 / 产品特写 / 人物出镜 / 动作过程 / 声音 / 已有素材。每章独立，缺章不影响其他章开工。

**② 每项写死规格六要素**

画幅 / 分辨率帧率 / 单段时长 / 机位运镜 / 光线时段 / 留白禁项

例：「竖屏 9:16，1080×1920，单段 5–8 秒，手持平视，白天自然光，画面左上留 1/5 空白放字幕，**不要拍到隔壁店招**」

**③ 高优先级 ≤10 项，★ 开工包 5–8 项**

★ 是「没有它就完全没法开工」的。其他可以后补。

**④ 能降门槛就降**

照片能解决的不要求视频；手机能拍的不要求稳定器。

---

## 过关（门 1 的后半）

- [ ] 没有「高清」「一些」「随便拍点」这类词
- [ ] 每项都能被店主拿手机照着拍出来
- [ ] ★ 开工包 ≤8 项，且都是真的必需
- [ ] 每项标了「用来做哪一镜」

**四项缺一项就退回。** 依据：某驾校清单改 4 版，每次都是因为规格写得像摄影指导。

---

## 需要什么能力 / 用什么

| | |
|---|---|
| 能力 | 出可打印/可转发的文档；能按客户实际条件裁剪要求 |
| 工具 | 任何文档工具；WorkBuddy 的 `client-brief` 可以自动出；没有就填模板 |

---

## 常见卡点

**要求写得像摄影指导。**

「4K、布光、轨道、稳定器」——客户是店主，一个人一部手机。

写清单时默念一句：**这张纸发给我妈，她能拍出来吗？**
