# 08 · 客户确认（生成前预审）

> 生成之前，把要做的东西一次性给客户看，确认了再花钱。
> **这一环省的不是时间，是返工。**

---

## 这一环接什么、交什么

| | |
|---|---|
| **接** | 07 的干净版分镜表 + 05 的人物图/声音样本 + 04 的素材清单 |
| **交** | 客户明确回复「确认」+ 一个锁定的版本号 |
| **谁做** | 你（人对人，不是 agent） |
| **过不了会怎样** | 生成完客户说「这不是我要的」，全部重做 |

---

## 为什么要单独设一环

真实情况是：**视频做出来之后，商家才提意见。**

那时候素材已经生成了，钱花了，时间也过了。改一句台词就要重抽三条。

**把意见提前到生成之前，成本差 10 倍。**

---

## 确认两块

### ① 格式与规格（六项）

| 项 | 写什么 |
|---|---|
| 画幅 | 9:16 / 16:9 / 1:1 |
| 分辨率 | 例：1080×1920 |
| 总时长 | 例：约 30 秒 |
| 平台 | 抖音 / 视频号 / 小红书 |
| 字幕 | 有无、语言、位置 |
| 交付形式 | 成片 / 素材包 / 两者 |

### ② 内容（五项）

| 项 | 给客户看什么 |
|---|---|
| 脚本 | 干净版分镜表，或口播稿 |
| 分镜顺序 | 静态排版图，或分镜表截图 |
| 人物形象 | 四列参考图 |
| 声音样本 | 15 秒 MP3 |
| 素材用法 | 哪些用他给的、哪些生成 |

**不要发提示词。** 客户看不懂，还会问「这是什么」，反而拖时间。

---

## 怎么给客户看（按配合度选）

| 形式 | 适合 | 怎么做 |
|---|---|---|
| **微信发文字 + 图** | 大部分小店 | 分镜表截图 + 人物图 + 一段说明 |
| **一页 PDF** | 稍微正规的客户 | 分镜 + 形象 + 规格，压成一页 |
| **当面对** | 大单 | 现场过一遍，当场定 |

---

## 确认话术（照抄）

```
【拍摄前确认】麻烦确认这几项，回"确认"我就开工

1. 画幅：竖屏 9:16
2. 时长：约 30 秒
3. 平台：抖音
4. 分镜：见下图（共 12 镜）
5. 出镜：您的数字人形象（见下图）
6. 声音：您的克隆声音（见下）
7. 素材：用您给的门头/菜品/环境，其余生成

有要改的直接说，改完再确认。
```

---

## 客户提意见，回到哪一环

| 意见类型 | 例子 | 回到 |
|---|---|---|
| **改文案 / 结构** | 「这句不要」「换个说法」 | [07 脚本改造](../07-脚本改造/) |
| **改形象 / 声音** | 「这个不像我」「声音不对」 | [05 身份资产](../05-身份资产/) |
| **改规格** | 「改 60 秒」「要发视频号」 | [02 素材清单](../02-素材清单/)（影响素材量） |

**不要在这一环直接改。**

改完前面要重新走一遍确认——不然改了这处忘了那处，到剪辑时对不上。

---

## 确认之后锁定版本

把版本号和日期写进文件：

```
分镜-v3（客户确认 2026-11-04）
```

**后面再改，版本号要升，并重新确认。**

不然到剪辑时说不清「客户当时确认的是哪一版」。

---

## 过关（五条）

- [ ] 客户明确回复「确认」（**不是**「行吧」「差不多」「嗯」）
- [ ] 格式规格六项都写了
- [ ] 分镜给客户看过（不是只给内部看）
- [ ] 人物图和声音样本给客户看过
- [ ] 确认日期和版本号记下来了

---

## 常见卡点

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 客户说「你看着办」 | 没给具体东西看 | 给他三个选项让他挑，不要问开放式问题 |
| 客户看完说「再想想」 | 没有截止点 | 「那我按这版开工，要改在生成前说」 |
| 确认完又改 | 没锁定版本 | 记版本号+日期，改一次升一版 |
| 客户只回「嗯」 | 不算确认 | 追问一句「那就按这个做了？」 |
| 大改动 | 前面某环没对齐 | 回对应环节重走，不要在这里打补丁 |
| 客户嫌麻烦不看 | 东西太多 | 只发一页：分镜图 + 形象 + 三行规格 |

## 深水区（可选）

走流程的项目，给客户看之前加一道**压力测试**：

| 问 | 不合格 |
|---|---|
| 一句话讲得清吗 | 要讲三分钟 |
| 每场都有变化吗 | 有场次只是交代信息 |
| 观众为什么要看下去 | 只能答「画面好看」 |

结构死的剧本和结构活的剧本，AI 生成出来一样干净——等剪辑台上发现，钱已经烧完。
