# 03 · 客户采集

> 清单发出去之后，客户真的开始拍。**这一段不需要 AI，需要的是把话讲清。**

| | |
|---|---|
| **上一步给我什么** | 已发出的素材清单（含 ★ 开工包） |
| **这一步交什么** | 客户拍回的原片 + 采集 SOP 执行记录 |

---

## 做什么

**① 把 SOP 对应章节整段发客户**

不要发链接、不要发文件让客户自己找。**把你需要的那一段文字直接复制到微信里。**

四类素材各有一段：门头与环境 / 产品特写 / 人物出镜 / 声音。

**② 数字人和声音优先启动**

数字人形象 + 声音样本是第一优先级——它们要 20 分钟，但**条件不满足就得重拍**（光线、背景、口型）。

先启动这两样，其他素材同步收。

**③ 三天规则**

清单发出后第 3 天，不等齐，按 ★ 开工包先排剪辑。

---

## 过关

- [ ] SOP 章节是**整段发出**的，不是「按清单拍」
- [ ] 数字人是**视频**不是截图
- [ ] 声音样本：60 字、约 13 秒、连读 3 遍
- [ ] 客户知道「拍不了」可以直接说（不是硬凑）

**「客户说拍不了」不是失败，是有效信息。** 它会进回收表的「无法拍」栏，后面改分镜。

---

## 需要什么能力 / 用什么

| | |
|---|---|
| 能力 | 能发文档、能把要求讲成大白话、能判断素材能不能用 |
| 工具 | 微信 / 企业微信 + [采集 SOP](../../03-话术/采集SOP.md)。**这一步不需要 AI** |

---

## 常见卡点

**只发一句「按清单拍」。**

客户看不懂「分辨率帧率」，也不知道「留白禁项」是什么意思。

正确做法：清单是给客户存档的，微信里发的是**分段的话**——「姐，先拍三样：门头、招牌菜出锅、你自己说一句话。手机竖着拍，别开美颜。」
