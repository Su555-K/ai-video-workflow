# 05 · 身份资产（人物 + 声音）

> 进生成前必做。**没有这两样，同一个角色在不同镜头里会换脸、换声。**
>
> 两条线，同一个人：**人物参考图**（`SKILL.md`）+ **声音样本**（本文「声音样本」一节）。

---

## 这一环接什么、交什么

| | |
|---|---|
| **接** | 客户提供的**真人照片**（正面全身 + 正面特写，最好有左右侧）+ **声音素材**，来自 [04 素材回收](../04-素材回收/) |
| **交** | 一张四列参考图（横版 3:2）+ 缺失角度标注 |
| **谁做** | [SKILL.md](SKILL.md)（character-reference-sheet v1.0.0） |
| **过不了会怎样** | 角色在每个镜头换脸、衣服跳色、发型变长变短 |

> **这一环是素材线，不是脚本的下游。** 素材一到就能做，不必等 06/07。
> 急着出片时，05 与 06/07 可以同时开工。

---

## 四列版式（固定，不要改）

```
┌──────────────┬────────┬────────┬────────┐
│              │        │        │        │
│   全身照      │ 正面   │ 朝左   │ 朝右   │
│  （不裁头脚）  │ 头肩   │ 60-75° │ ~90°   │
│              │        │        │        │
├──────────────┴────────┴────────┴────────┤
│  全身照  │  正面  │  左侧  │  右侧       │  ← 深灰底标签
└──────────────────────────────────────────┘
   30%      23.3%    23.3%    23.4%
```

四条硬规则：

1. **第 1 列头发顶部和鞋底都要完整**，不裁头不裁脚，不把腿拉长
2. **标签按画面朝向命名**——「左侧」指画面左边，不是人物的左边。要按解剖学方位就得重新定义并校正标签
3. **同一真人、同一发型、眼镜、服装、肤色**，灰棚背景，柔和均匀光
4. **严禁右侧重复一排特写、加第五列、贴多张相似头像**

---

## 最重要的一条：这张图是资产，不是输入

**四列图给人看、给团队存档、给平台做参考板。不要直接把它喂给生成模型。**

原因：拼图喂进去，模型会平均四张脸，出来的人既不像正面也不像侧面。

正确做法：

```
四列图（资产，存档/交接用）
    ↓ 从里面裁
单张正面特写  →  喂给生成模型（配 input_fidelity=high）
    ↓
侧/背角度  →  用正面图推，不要用拼图推
```

这一条和门 3 的「三类参考」是一件事的两面：门 3 说「四视图拼图不能直接喂」，这里给出为什么以及怎么绕。

---

## 缺图怎么办

| 缺什么 | 怎么办 | 能不能说"精确还原" |
|---|---|---|
| 缺全身照 | 可做推断版 | ❌ 不能，衣裤鞋身材都是推断 |
| 缺侧面 | 可推断，标「未见原始侧脸，AI 推断」 | ❌ 不能，高保真用途需补拍 |
| 照片强光/镜片反射 | 可修掉眩光，不磨皮 | ✅ 可以，但要保留肤质 |
| 生成的脸和照片不一致 | **不得作为合格版交付** | — |
| 中文标签乱码 | 先生成留空底栏，后期叠字 | ✅ 可以，别为了改字重生成人脸 |

**「模型推断 / 未核验」这六个字必须写在交付说明里。** 这是这份 skill 最专业的地方——它不假装能还原看不见的东西。

---

## 上游缺料时的处理

这个环节最常见的死法不是做不好，是**客户给的照片不合格**：

| 客户给的照片 | 判断 | 动作 |
|---|---|---|
| 只有自拍，没有全身 | 缺全身 | 先问要一张站立全身照，或做推断版并标注 |
| 全身照但是坐着/半身裁切 | 缺鞋、缺腿型 | 同上 |
| 多张照片里像不同的人（不同年份/不同体重） | 有身份冲突 | **先核对，不要混合面孔生成** |
| 照片是别人（员工/网红） | 肖像权问题 | 必须确认授权，否则不能做 |

最后一条是法律问题，不是技术问题。**没有授权的人物照片，不要做成数字人资产。**

## 声音样本（第二条线）

> 客户要克隆声音时走这里。**和人物形象是同一个人、同一批素材。**

### 上游怎么判断要不要做

需求清单里有一项「**是否需要克隆人物**」。选"需要"，才进这一步；选"不需要"，这一节整段跳过。

### 先给台词，再让他录

**不要让他"随便录一段"。** 素材清单里直接给一句通用文本：

> 今天天气怎么样？

配三条要求：

| 项 | 怎么说 |
|---|---|
| **内容** | 照这几个字念，不要即兴加词 |
| **语速** | 正常说话速度，不用刻意放慢或加快 |
| **环境** | 安静的房间，关掉电视和音乐 |

**为什么给固定台词**：不指定内容，客户会念一段自我介绍或广告词，语气和我们要用的场景对不上。指定一句日常问句，音色最中性，也没有情绪偏向。

### 客户会怎么发回来

| 形式 | 常见问题 |
|---|---|
| 一段视频（有画面有人声） | 人声被背景音乐盖住 |
| 一段录音（手机录的） | 环境噪音、回声 |
| 微信语音 | 音质差、时长碎片化 |

**超时了不用退回去重录**，我们自己剪。

### 处理四步

**① 转格式** → MP3

音视频都能转。工具不限：WorkBuddy、剪映、ffmpeg、任何转换工具。

**② 截取 → 15 秒以内**

从一整段里取连续的一段。**不要拼接不同时间点的句子**——音色会跳。

> 15 秒是**平台限制**，不是对商家的要求。商家给多长都收，我们自己剪。
> **不要拿这个去要求客户**——客户只需要照台词念，剪到 15 秒是我们的活。

**③ 去杂 → 只留一个人声**

剪掉：背景音乐、环境噪音、第二个人说话、呼吸声过重的段落。

**④ 验完整 → 首尾必须是完整句子**

开头不能是"……然后"，结尾不能是半句。听第一句和最后一句，能独立成句才算。

### 验收（五条，能勾）

- [ ] 格式是 MP3
- [ ] 时长 ≤ 15 秒
- [ ] 开头是完整句子的开头（不是承接上文的半句）
- [ ] 结尾是完整句子的结尾（不是被切断的半句）
- [ ] 全程只有一个人在说话，无音乐、无环境音

**五条缺一条，重剪。** 样本脏了，克隆出来的声音会一直带着那个问题。

### 常见卡点

| 情况 | 怎么办 |
|---|---|
| 人声被背景音乐盖住 | 先做一次人声分离，再截 |
| 一开口是"啊……那个……" | 从第二句开始截，别从第一个字截 |
| 15 秒内凑不出完整句 | **选两个短句，不要一句长句被截断** |
| 商家问"要录多长" | 回"就念这一句，念完多发几遍也行，我来剪" |
| 老板给了照片，声音是员工的 | **必须同一个人**，问清再动手 |
| 客户只有方言/极快语速 | 要一段正常语速的，或用现有素材里的正常段落 |

### 命名

```
<人物ID>-形象.png     人物参考图
<人物ID>-声音.mp3     声音样本
```

同一个人的两样东西用同一个 ID，后面生成时不会串。

## 验收：什么样算做完

**人物图（六条）**

- [ ] 四列齐全，无第五列、右侧无重复
- [ ] 第 1 列头脚完整
- [ ] 四个标签是「全身照 / 正面 / 左侧 / 右侧」
- [ ] 同一人：发型、眼镜、服装、肤色一致
- [ ] 缺的角度已标「模型推断 / 未核验」

**声音样本（五条，只在客户要克隆时查）**

- [ ] MP3 格式，≤15 秒（平台限制，我们剪，不要求商家）
- [ ] 开头是完整句子的开头
- [ ] 结尾是完整句子的结尾
- [ ] 只有一个人声，无音乐无环境音
- [ ] 和人物图是同一个人

**十一条全过（不克隆声音则是六条），这一环才算完。**
