# 01 · 需求确认

> 新客户进来第一步。**这一步错了，后面全废。**

| | |
|---|---|
| **上一步给我什么** | 客户的微信原话、品牌资料、对标视频（有什么算什么） |
| **这一步交什么** | **一表通**（对外，客户填）+ **推导册**（对内，不外发） |

---

## 做什么

**① 先判制作方式**（四问，答案不定不许往下走）

1. 有现成素材吗？
2. 要出人吗？（真人 / 数字人 / 不出现）
3. 客户能拍吗？
4. 多长？

**② 列事实，分三档**

| 档 | 来源 | 写法 |
|---|---|---|
| 原话 | 客户微信里说过的 | 直接引，不改写 |
| 资料 | 品牌介绍、菜单、海报 | 摘录，标出处 |
| 反推 | 你从行业常识猜的 | **写成判断行，让客户划掉** |

**③ 能推的写成判断行**

不要问「您的目标客群是谁」，写「我理解主要是 25–40 岁本地家庭客，对吗？」——客户只需划对错，不用组织语言。

**④ 只留 ≤3 个真问题**

推不出来的才问。问题多了客户就不填了。

---

## 过关（门 1 的前半）

- [ ] 制作方式四问有明确答案
- [ ] 对外版**没有**「为什么问」、**没有**日期承诺、**没有**推导过程
- [ ] 判断行 ≥5 条（说明你真的推过，不是把问题全丢给客户）
- [ ] 真问题 ≤3 个

**制作方式没定，不许出素材清单。** 依据：某驾校素材清单改了 4 版，根因是第 9 轮才说清「做的是图生视频 + 克隆形象」。

---

## 需要什么能力 / 用什么

| | |
|---|---|
| 能力 | 把散乱信息整理成结构化表格；能导出 DOCX 或在线文档 |
| 工具 | WorkBuddy 的「需求确认及素材」skill；没有就填 `02-模板/` 手填；DeepSeek 等可以帮你梳理，但**判断行必须你自己下** |

---

## 常见卡点

**把基础课的「需求卡」直接给客户填。**

需求卡问的是「观众看完留下什么」「主要事件」「表达方式」——这些是创作语言，客户看不懂也不会答。

客户只回答「是什么」，不回答「为什么」。所以对外用一表通（商业条件），对内用推导册（创作意图）。

## 深水区（可选）

客户没 brief、只有一句「我要个片子」时，不要直接拆需求，先走一遍**概念锚定**。

四个问题：给谁看 / 看完要他做什么 / 一句话说清讲什么 / 结局落在哪。
**答不上来就别往下走**——后面每一站都会返工。
