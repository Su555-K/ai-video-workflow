## 为什么空着

三个原因：

1. 现有项目都还没交付完，谈不上「成功案例」
2. 案例要脱敏，脱敏要客户同意，这一步还没做
3. 与其放一个半成品，不如空着

---

## 案例该长什么样

一个案例不是一个成片链接，是**一条走完全流程的记录**：

```
04-案例/某驾校-清单四版/
├── README.md        这个项目发生了什么（问题 → 改了什么 → 结果）
├── 01-需求.md       一表通（脱敏版）
├── 02-清单-v1.md    第一版
├── 02-清单-v4.md    第四版
└── 对比.md          为什么改了三次
```

**最有价值的不是最后那版，是中间改了什么、为什么改、谁提出来的。**

---

## 收录标准

- [ ] 走完至少 01–07
- [ ] 有真实的返工记录（一次就成的项目没有教学价值）
- [ ] 已脱敏：客户名换成行业代号，无手机号、地址、真人照片
- [ ] 客户同意公开，或完全无法反查到具体商家

---

## 脱敏规则

| 原 | 换 |
|---|---|
| 具体商号 | 某 + 行业（某驾校 / 某烤肉店 / 某甜品店） |
| 老板姓名 | 客户 |
| 门店地址 | 删 |
| 真实报价 | 删或改区间 |
| 人物照片 | 不放 |

**只改名字，不改事实。** 「清单改了 4 版」必须是真的——脱敏不是为了把案例写好看。
