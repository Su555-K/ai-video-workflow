# 安装与开始

> 第一次用这套流程，按这里走。**15 分钟能跑起来。**

---

## 一、要装什么

这套流程用到 5 个 skill，**不用全装，按你要跑的环节装**：

| skill | 管哪一环 | 仓库里有吗 |
|---|---|---|
| `client-brief` | 01 需求确认 + 02 素材清单 | 否（WorkBuddy 市场或团队包） |
| `annotate-video-language` | 06 参考拆解 | 否（团队包） |
| `shortvideo-script-doctor` | 07 脚本改造 | **是**（`01-流程/07-脚本改造/`，MIT） |
| `ai-visual-director` | 09 提示词编译 | **是**（`01-流程/09-提示词编译/`） |
| `character-reference-sheet` | 05 身份资产 | **是**（`01-流程/05-身份资产/`） |

> 早期版本这里写的是用 `seedance-storyboard` 管「脚本改造」，那是另一套工具，和本仓库的 `shortvideo-script-doctor` 不是一回事。仓库实际发的是后者。

**只跑前制段的话，至少装 `client-brief` + `ai-visual-director`。**

---

## 二、怎么装（WorkBuddy）

1. 把 skill 整个目录（不是单个文件）放到：
   ```
   ~/.workbuddy/skills/<skill名>/
   ```
2. 目录里必须有 `SKILL.md`，且在**根层**，不要多套一层文件夹
3. 重启 WorkBuddy
4. 在对话框输入 `/`，看列表里有没有它

**不需要改配置、不需要注册。** 手工放进目录就会被扫描收录。

---

## 三、怎么验证装成功

三个检查，全过才算装上：

- [ ] 输入 `/` 能看到 skill 名字
- [ ] 问它「你能做什么」，回答在它的职责范围内
- [ ] 给一个小任务，它按 SKILL.md 的流程走（不是随便答）

**第三个最关键。** 前两个能装作在，第三个骗不了。

---

## 四、第一次跑什么

不要拿真实客户练手。用这个：

> 帮我把这段 30 秒竖屏招生脚本转成逐镜提示词卡，标出哪些镜头 AI 生成风险高。

（脚本随便找一段，或用 `01-流程/09-提示词编译/examples/45秒21镜-示例.md` 里的）

看它有没有做这四件事：

1. 先问清模式（A/B/C/D）
2. 版本锁定（记下脚本版本、画幅、时长）
3. 七类冲突排查
4. 声明输出档位（轻量/加项/完整）

**四件都做了，说明装对了。**

---

## 五、学生用的正确姿势

| 阶段 | 你要做的 |
|---|---|
| 第 1 天 | 装 skill，跑一次上面的测试 |
| 第 2–3 天 | 拿一个模拟项目走 01→07，不提 Issue |
| 第 4 天起 | 上真实项目，**卡住就提 Issue** |

**提 Issue 不需要会 Git**：仓库页 → Issues → New issue → 选「问题反馈」→ 填五栏。

---

## 六、常见问题

**Q：skill 不出现？**
A：检查是不是多套了一层目录（`skills/ai-visual-director/ai-visual-director/SKILL.md` 是错的）。

**Q：装了两个版本，用哪个？**
A：删掉旧的。**同一环节不要装两个 skill**，它会两边都参考，输出混乱。

**Q：我有自己的模型，不用 WorkBuddy？**
A：把整个 skill 目录给你的 agent，让它先读 `SKILL.md`，再按需读 `references/`。流程不变，只是宿主不同。

**Q：必须联网吗？**
A：`ai-visual-director` 不调接口，纯文本工作。只有「生成后验收」需要 ffmpeg 抽帧。
