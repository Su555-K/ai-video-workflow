# 干净分镜表 · 音画分离版

> 这是给下游用的**唯一**分镜文件。诊断过程、改稿批注、删除标记全部留在上一环，这里只留结果。

**为什么必须音画分离**：台词和画面写在同一行，视频模型会把台词也「画」出来——这是生成出字幕的头号原因。详见 [文字策略排查](../../01-流程/09-提示词编译/文字策略排查.md)。

---

## 一眼看懂结构

```
┌─────────────────────────────────────────┐
│  上表：画面   → 喂给视频模型（只描述看图什么）│
├─────────────────────────────────────────┤
│  下表：音频   → 喂给配音/剪辑（只描述听什么）│
└─────────────────────────────────────────┘
              ↑ 两张表用【镜号】对齐
```

**同一个镜号，上表说什么、下表说什么，合成时按镜号拼。**

## ❌ 错误写法（会出字幕）

| 时间 | 画面 | 声音 |

| 0–2s | 和牛摆盘推近 | 女声：看这个 M 级和牛 |

**问题**：台词和画面在同一格，模型分不清哪个是要画的。

## 交付时怎么拆

| 目标 | 给什么 | 不要给什么 |
|---|---|---|
| **视频模型** | 上表（画面 + 素材 + 生成备注） | ❌ 旁白原文 |
| **配音 / TTS** | 下表（旁白原文 + 断句） | ❌ 画面描述 |
| **剪辑** | 两张表 + 音画对齐说明 | — |
| **客户确认** | 简化版（镜号 + 画面 + 旁白，一行一镜） | — |

**给视频模型的提示词，一句台词都不能出现。** 台词只出现在音频表里。

---

## 三个禁忌

| # | 禁忌 | 后果 |
|---|---|---|
| 1 | 台词写进画面描述 | 生成出字幕 / 人物嘴型对不上 |
| 2 | 画面里写形容词（高级、温馨、有质感） | 模型无法执行，每次结果随机 |
| 3 | 素材列留空或写「待定」 | 下游不知道这条是拍、是找、还是生成 |


```
[ ] 素材列有值（文件名 / 待采·xx / 生成）
```
