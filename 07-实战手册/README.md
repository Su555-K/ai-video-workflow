## 为什么单独放，不放进流程

流程节点是**线性**的：接什么 → 做什么 → 交什么。

这两份是**查表**的：出现症状 → 找原因 → 决定改不改。

混进流程会让"下一步做什么"变得不清楚。放在这里，需要时查，平时不看。

---

## 01 生成翻车诊断

六大类症状对照：

```
人物类 / 动作类 / 镜头类 / 光线与色彩类 / 文字类 / 画面内容类 / 综合类
```

每类给：症状长什么样 → 30 秒内能判定的原因 → 改不改。

还有一节最重要：**什么时候必须放弃生成**（改走实拍或后期），别在物理上做不到的事上烧钱。

---

## 02 素材可用性判定

**顺序很重要**：素材到手先判定，再谈需求和报价。顺序反了就会承诺做不了的东西。

三档判定 + 照片类 + 视频类 + **不能救的时候怎么办（不重拍）**。

最后一节最实用：素材通常补不了，所以重点不是"让客户重拍"，是"这份素材能做成什么"。

---

## 两份的共同点：标了证据等级

```
实例 = 真实踩过的坑
推演 = 按原理推的，未实测
```

看到 `实例` 可以信，看到 `推演` 要自己验一遍。

**这个标记法是整套流程里最该学的习惯**——它让读者知道哪句能直接用、哪句要小心。
