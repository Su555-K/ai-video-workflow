# 03 · 成片效果诊断

> 跟 `01-生成翻车诊断` 不一样：那份管「画面崩了」，这份管「画面没崩，但片子不好看」。
> 每条的格式统一：**最可能原因 / 30 秒判定 / 改法 / 放弃条件**。

---

## 一、一致性类

### 1. 换个镜头就像换了个地方

| | |
|---|---|
| 最可能原因 | 没做场景资产，每镜独立生成 |
| 30 秒判定 | 两镜的背景放一起，门窗、桌角、光源方向对得上吗 |
| 改法 | 先出一张**能概括全段空间信息的全景图**，所有镜头都挂它做参考。不用画分镜 |
| 依据 | 「一张能概括你这段剧情所有人物和镜头运动会涉及到的空间信息的全景图，不需要分镜」 |
| 放弃条件 | 每镜都是特写、看不到环境 → 不需要场景资产 |

### 2. 人物左右关系跳

| | |
|---|---|
| 最可能原因 | 没有空间锚点，正反打从两侧拍 |
| 30 秒判定 | A 在画面左边，切到 B 时 B 应该在右边。反了就是越轴 |
| 改法 | 同一场戏所有机位都在轴线同侧；相邻两镜**机位夹角 ≥30°**，低于这个数观众读作穿帮 |
| 放弃条件 | 故意越轴制造混乱感（恐怖/失衡），但只能有一次 |

### 3. 道具、伤势、时间前后矛盾

| | |
|---|---|
| 最可能原因 | 没有连续性记录，靠记忆 |
| 30 秒判定 | 列出这场出现的所有物件，逐个问「上一场它在哪」 |
| 改法 | 建一张连续性表：物件 / 位置 / 状态 / 出现场次。每场开拍前核一遍 |
| 放弃条件 | 单片、单场景、无跨场物件 → 不用建 |

## 二、表演类

### 4. 情绪出不来，只会皱眉瞪眼

| | |
|---|---|
| 最可能原因 | 情绪写成了形容词（"他很愤怒"），没写可见行为 |
| 30 秒判定 | **把台词去掉，光看画面能知道他什么情绪吗** |
| 改法 | 写六项：眼神看哪、呼吸节奏、下颌松紧、手在干什么、反应延迟几秒、身体朝向 |
| 依据 | 「把情绪写成眼神、呼吸、下颌、手部和反应延迟」 |
| 放弃条件 | 远景、看不清脸 → 情绪交给机位和光，不靠表情 |

### 5. 眼神死，像待机

| | |
|---|---|
| 最可能原因 | 眼睛里没有目标物 |
| 30 秒判定 | 暂停看眼睛，能说出他在看什么吗 |
| 改法 | 提示词里写「视线落在 ___」；没有目标物就造一个（门、手机、对方的手） |
| 放弃条件 | 空镜、背影 → 不适用 |

### 6. 动作没有重量

| | |
|---|---|
| 最可能原因 | 只写了招式，没写受力和惯性 |
| 30 秒判定 | 慢放看：接触瞬间身体有没有反弹、停顿、失衡 |
| 改法 | 写清重心移动、受力方向、疼痛反应、动作结束后的身体状态 |
| 放弃条件 | 一秒以内的快切 → 观众看不出来，不用管 |

## 三、结构类

### 7. 片子平，看完没感觉

| | |
|---|---|
| 最可能原因 | 全片同一个情绪，没有变化 |
| 30 秒判定 | 给每一场写一个情绪词，**词是不是都一样** |
| 改法 | 按「收紧」（越来越近、越来越低、越来越慢）或「松开」（越来越远、加负空间）排 |
| 依据 | 「全场同一个情绪＝平」 |
| 放弃条件 | 15 秒以内的信息流广告 → 只要求一个情绪打透，不需要曲线 |

### 8. 前 3 秒没钩子

| | |
|---|---|
| 最可能原因 | 从"交代背景"开始，不是从"问题"开始 |
| 30 秒判定 | **把前 3 秒单独截出来放，你会继续看吗** |
| 改法 | 信息前置：先给结果/冲突/反常，再交代 |
| 放弃条件 | 品牌形象片，观众是被投放触达的 → 可以慢起 |

### 9. 结尾塌

| | |
|---|---|
| 最可能原因 | 最后一个镜头是"结束动作"，不是"情绪落点" |
| 30 秒判定 | 最后一镜截图，能独立当海报吗 |
| 改法 | **末态锁定**：写清最后一帧人物在哪、什么姿势、什么表情、光在哪 |
| 放弃条件 | 系列片的中间集 → 结尾要留钩子，不留落点 |

## 四、节奏类

### 10. 台词塞不进时长

| | |
|---|---|
| 最可能原因 | 字数超了语速 |
| 30 秒判定 | 字数 ÷ 秒数。中文口头语速约 **4–5 字/秒**，超过 5.5 就一定赶 |
| 改法 | 三条路：删字 / 延长时长 / 拆成两镜。**不许加速，也不许让模型念快** |
| 放弃条件 | 无（语速是硬约束） |

### 11. 单镜太长，观众走神

| | |
|---|---|
| 最可能原因 | 一镜里没有信息变化 |
| 30 秒判定 | 这镜从头到尾，观众知道了什么新东西 |
| 改法 | 要么在镜内加一个变化（人走进/光变/手部动作），要么拆成两镜 |
| 放弃条件 | 刻意的长镜头凝视（艺术片），但全片不超过 2 处 |

### 12. 剪辑接不上

| | |
|---|---|
| 最可能原因 | 接点没设计，默认硬切 |
| 30 秒判定 | 停在上一个镜头的最后一帧，下一个镜头第一帧——中间少没少东西 |
| 改法 | 选一个接点：动作切（同一动作跨镜）/ 遮挡切（有东西挡一下）/ 声音先行（下一镜的声音提前进来）/ 首尾帧桥 |
| 放弃条件 | 无 |

---

## 五、怎么用这一份

1. **先看片，不要先看文档。** 把片子连放三遍，记下「哪里让你出戏」。
2. 拿那句出戏的话，来这张表里找**症状**，不是找流程。
3. 每条只给一个改法，先改它，别同时改三处。
4. 改完再看一遍，**问自己「刚才那个出戏的感觉还在吗」**。

---

## 附：边界

- 这份只管"看片能看出来"的问题，不管模型参数、接口、分辨率
- 判断依据来自真实返工记录与外部方法（标注在"依据"行），没有数据支撑的地方不写数字
- 遇到表里没有的症状：记到 `06-问题/模板.md`，同一问题被 3 个人遇到才进这张表
