# 时长核算表 · 一页纸

> ⚠️ **本表是纯口播的快速粗算**（字数 ÷ 语速），用来快速判断「客户给的秒数够不够」。
> 精确核算用 `01-流程/07-脚本改造/scripts/calc_pace.py`：**音节 ÷ 语速 × 1.1 + 停顿**。两者能差 10–20%，差在数字读法（138 读作「一百三十八」，5 个音节）、标点停顿、口语冗余。
> 排进分镜表的时长必须用后者，不能用本表的数字直接填。

> 用途：客户说"做 30 秒"之前，先算一遍。**时长算错，后面全白做。**
> 这张表是 P0 里最便宜的一张，也是最容易救命的一张。

---

## 一、公式

```
口播秒数 = 字数 ÷ 语速
需要字数 = 目标秒数 × 语速
```

**中文口播语速基准**：

| 语速 | 字/秒 | 什么场景 |
|---|---|---|
| 慢、克制 | 4.0 | 品牌片、情绪片、长辈讲话 |
| **正常** | **4.5–5.0** | 大多数口播、讲解 |
| 快、急促 | 5.5 | 促销、节奏快的短视频 |
| **不可能** | **≥6.5** | 出现这个数，一定是客户估错了 |

## 三、真实案例（某餐饮招商项目）

客户自写口播 **412 字**，表格标注 **58 秒**。

```
412 ÷ 58 = 7.1 字/秒  ← 不可能
412 ÷ 4.5 ≈ 92 秒
412 ÷ 5.0 ≈ 82 秒
```

**实际应在 82–92 秒之间**，最终按 83 秒切成 4 段（20/18/25/20）。

**处理方式**：
- 告知客户：要压到 60 秒只能**删字**，不能加速
- 加速会让口播失真、字幕跟不上、呼吸节奏乱
- 删字优先删：重复的形容词、自我介绍、品牌口号

## 四、客户给了时长，你怎么验

| 客户说法 | 你要做的 | 结果 |
|---|---|---|
| "做 30 秒" | 问他有多少字 / 看他给的文案 | 超过 150 字 → 告诉他实际会是多久 |
| "按这个文案做" | 数字数，算秒数 | 和平台限制对齐（见下） |
| "随便，你定" | 按 4.5 字/秒算一个，报给他确认 | 写进分镜表的时段列 |

## 五、和平台限制对齐

算出来的秒数还要过两道关：

| 关 | 规则 | 冲突怎么办 |
|---|---|---|
| 平台单条时长 | 多数 ≥4s，Seedance ≤12s | 超过 12s 就要拆段，段间用首尾帧接 |
| 全片段落数 | 实践 ≤4 段，每多一段多一次漂移 | 超过 4 段：缩时长 / 改机位 / 重跑 |
| 单镜计划时长 | 2s 的镜也要生成 4–5s 再裁 | 生成留余量（+1~2s） |

**一张表连起来看**：

```
文案 412 字
  → 实际 83 秒（不是 58 秒）
  → 拆 4 段（20/18/25/20）
  → 每段 18–25 秒生成（不超过 20s 实践上限）
  → 每段留 5–6 秒余量挑最稳的表演
```
