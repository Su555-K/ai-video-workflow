# 单镜验收单 · 模板（9 项：8 项基础 + 1 项商用）

> 用途：每生成一批候选，逐镜打这张表。**没过验收的镜头不许进粗剪。**
> **8 项来自基础课的单镜验收标准，第 9 项「可交付性」是商用加的一条。共 9 项。**

---

## 一、逐镜打分表

**项目：**____________  **镜号：**S__  **版本：**v__  **模型/入口：**____________

| # | 检查项 | 看什么 | 通过 | 不通过 | 备注（写具体现象） |
|---|---|---|---|---|---|
| 1 | 人物与物件 | 身份、服装、产品没变；同一张脸 | ☐ | ☐ | |
| 2 | 主动作 | 只发生了预期的那一个动作 | ☐ | ☐ | |
| 3 | 摄影机 | 运动方向正确，没有突跳/漂移 | ☐ | ☐ | |
| 4 | 物理关系 | 手、物体、接触关系自然，不多指不穿模 | ☐ | ☐ | |
| 5 | 前后接续 | 起止状态能接上一镜/下一镜 | ☐ | ☐ | |
| 6 | 时长 | 动作完整，且留出剪辑余量 | ☐ | ☐ | |
| 7 | 声音 | 没有错位、没有意外说话、该停的停了 | ☐ | ☐ | |
| 8 | 可用程度 | 能直接用，或明确知道怎么修 | ☐ | ☐ | |
| 9 | **可交付性** | 画面里没有别家 logo / 过期价格 / 无授权肖像 / 乱码中文 | ☐ | ☐ | |

**判定规则**：1–8 项全过、且第 9 项无问题 → 过；第 9 项任何一条不过 → 一律退回，不管画面多好看。

---

## 二、四分支处置（必选一个）

| 分支 | 什么时候用 | 要写什么 |
|---|---|---|
| **A 可用** | 9 项全过 | 直接标"选用"，进粗剪 |
| **B 重做这一镜** | 关键动作缺失、身份变了、轨迹错、物理崩 | 写清"重做时只改哪一项" |
| **C 局部修补** | 问题范围明确（屏幕文字、字幕、简单声音） | 写清"补什么、谁来补" |
| **D 待复核** | 条件缺失或标准有争议（客户没确认某个点） | 写清"缺什么、谁拍板" |

**不许出现的写法**："感觉不太对""再抽一版看看""有点怪"。**必须指到具体项。**

---

## 三、单镜记录格式（直接抄）

```
S03 v02 ｜ 只改：动作描述（加"停止并悬停"）｜ 结果：停止可读，身份与机位一致 ｜ 选用
S03 v03 ｜ 只改：速度档位 ｜ 结果：变慢但手部变形 ｜ 退回·物理关系 ｜ 保留 v02，不覆盖原件
```

**规则**：
- 每次只改一个变量
- 新版本不覆盖旧版本
- **不默认最新版最好**：v03 修好动作但破坏身份，就继续用 v02

## 四、整片验收（单镜全过后才做）

| # | 检查项 | 通过 | 说明 |
|---|---|---|---|
| 1 | 叙事：不看旁白，仍能看懂发生了什么 | ☐ | |
| 2 | 字幕：不遮主体，和音轨对齐 | ☐ | |
| 3 | 音量：人声清楚，音乐不压话 | ☐ | |
| 4 | 合规：价格/资质/绝对化用语/肖像授权 | ☐ | |
| 5 | **光影连贯**：相邻镜头的来源方向、色温一致，没有跳光 | ☐ | 判据见 `01-流程/09-提示词编译/references/anti-ai-look.md` |

## 五、一句话自检

> **这一镜有没有完成它的任务？**
>
> 停手没出现，就算光线漂亮也没有完成第 3 镜。

先看任务，再看美感。
