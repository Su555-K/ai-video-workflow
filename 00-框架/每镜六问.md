# 每镜六问：分镜环节的验收表

> 用途：学生写完分镜，自己走一遍这张表。**六个格子填不满，就是没想清楚。**
> 这张表是唯一一个「当场就能判对错」的工具，不需要老师看片。

---

## 一、先记一句总纲

> **情绪 = 观众与主体的距离 + 观众相对主体的高度 + 观众被允许看多久。**

机位不是风格选项，是**情绪的物证**。

大多数片子"很平"，不是模型不行，也不是词不够——是机位被当成了风格标签（"我要电影感，加个低角度"），而不是情绪的证据。

所以顺序要倒过来：**先说这一镜要让观众感觉到什么，再说相机在哪。**

---

## 二、六问表

每镜填一行。**同一条只能有一个答案，不能自相矛盾。**

| # | 问 | 取值 | 它改变什么 |
|---|---|---|---|
| 1 | **距离**是哪个？ | 大远景 / 远景 / 全景 / 中景 / 近景 / 特写 / 大特写 | 信息量。越近信息越少、情绪越重 |
| 2 | **高度**是谁在上？ | 虫视 / 地面 / 平视 / 高位 / 俯拍 / 鸟瞰 | 权力。仰＝被拍的人强，俯＝被拍的人弱 |
| 3 | **朝向**让观众站谁那边？ | 正面 / 侧面 / 四分之三 / 背面 / 过肩 / 第一人称 | 关系。看哪一面，就决定观众站在谁那边 |
| 4 | **焦段**是撑开还是压扁？ | 广角 / 标准 / 长焦 / 微距 ＋ 浅景深或深焦 | 空间。广角撑开、长焦压扁 |
| 5 | **运动**的种类/速度/终点？ | 固定 / 推 / 拉 / 摇 / 移 / 升 / 手持 / 环绕 / 变焦 | 情绪强度 + 观众停留时间 |
| 6 | **接点**是什么切？ | 硬切 / 动作切 / 遮挡切 / 首尾帧桥 | 节奏。单镜再好，接不住也是白拍 |

---

## 三、三个最常见的填错方式

### ❌ 错法一：自相矛盾的组合

```
俯拍虫视 / 微距大远景 / 中景特写
```

模型会**随机挑一个**执行，你写的那几个字等于白写。

**改法：** 一次只给一个距离、一个高度。想变，就在镜内写"从 X 推到 Y"。

---

### ❌ 错法二：运动只写"有情绪"

```
镜头缓慢推进，很有情绪
```

运动有且只有三个参数：**种类 + 速度 + 终点**。缺任何一项，模型都会自己发挥——而它发挥的方式通常是"缓慢漂浮"。

**改法：**

```
6 秒内从全景推到近景，终点停在他握着信纸的手；除此以外相机固定
```

---

### ❌ 错法三：全片同一个机位

同一主体连续两个镜头，**机位夹角至少变 30°**。

低于这个数，观众读到的不是"剪辑"，是**穿帮**——他会以为画面跳了一下。

**改法：** 相邻两镜至少变一个维度（距离、高度、朝向、焦段，任选其一）。

---

## 四、从剧本到镜头：三行剧本 → 五镜

**剧本：**

```
她把便签折好放进口袋。灯没开。一句话不说。
```

**拆镜：**

| 镜 | 距离 | 高度 | 朝向 | 焦段 | 运动 | 接点 |
|---|---|---|---|---|---|---|
| 1 | 中景 | 平视 | 背面 | 标准 | 固定 | 硬切 |
| 2 | 特写 | 平视 | 侧面 | 长焦浅景深 | 微推，2 秒 | 动作切（手入画） |
| 3 | 大特写 | 平视 | 正面 | 微距 | 固定 | 遮挡切（手挡住脸） |
| 4 | 全景 | 高位 | 背面 | 广角 | 固定，停 4 秒 | 硬切 |
| 5 | 大远景 | 鸟瞰 | — | 广角 | 缓慢升 | 出 |

**注意三件事：**

1. 每一镜只干一件事（交代 / 情绪 / 关系 / 空间），不贪心
2. 第 4 镜故意停 4 秒——**停留时间本身就是内容**
3. 接点全是"动作切"和"遮挡切"，不是硬切，因为硬切在这个情绪里会显得生硬

---

## 五、和提示词环节的接口

六问填完，直接能拼成提示词，顺序是：

```
[镜头句在最前] 距离 + 高度 + 朝向 + 焦段 + 运动（种类/速度/终点）
[然后] 主体描述
[然后] 光线与色彩
[最后] 风格与画质
```

**镜头句放最前面**，是因为模型对开头最敏感。放后面会被主体描述盖过去。

---

## 六、这张表不用背

写的时候把表打开，一行一行填。**填到第 5 镜你会开始烦——那就说明你在真的想，不是抄模板。**
